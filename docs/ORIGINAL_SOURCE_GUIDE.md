# 고모 창작실 — 원문 자동 검색·가져오기·저작권 검증 사용자 가이드

## 1. 개요

고모 창작실(GOMO Create)의 작품 정보 화면에서는 **장르·저자·제목**을 입력한 뒤 본문을 채우고, 사용자가 검토·수정한 다음 기획 분석으로 넘어갑니다. 저작권 검토는 다음 단계 진행을 막지 않습니다.

권장 사용 흐름:

**새 작품 만들기 → 장르·저자·제목 입력 → 「제미나이로 원문 가져오기」 또는 파일 첨부/드래그앤드랍 또는 직접 입력 → 본문 검토·수정 → 기획 분석**

선택적으로 **「원문 찾아 채우기」**(위키문헌·Gutenberg·공유마당·URL, 성경 장르에서는 책·장·절 선택기도 포함)로 본문을 채울 수 있습니다. 성경 장르에서는 번역본을 고른 뒤 제목(예: 시편 23편 1~6절)만으로 「제미나이로 원문 가져오기」를 쓸 수 있습니다.

---

## 2. 지원하는 원문 입력 방식 (4+1)

1. **작품 검색**
   - **한국어/영어 위키문헌 (Wikisource)**: 공식 MediaWiki API로 작품 검색, 원문 추출(시 행·연 구분 보존), `{{머리말}}` 판본 정보 및 라이선스 틀(`PD-old-70`, `PD-old-100`, `PD-KR`, `CC` 등) 확인.
   - **Project Gutenberg (Gutendex)**: 영문·다국어 고전 검색 및 UTF-8 원문 가져오기(미국 기준 게시 안내 및 한국 보호기간 별도 검토 표시).
   - **한국저작권위원회 공유마당 (`gongu.copyright.or.kr`)**: `robots.txt` 정책이 자동 파일 다운로드(`/gongu/wrt/cmmn/wrtFileDownload.do`, `/gongu/cmmn/file/fileDown.do`)를 차단하고 있어 자동 우회 수집을 하지 않고, **「공유마당 공식 사이트에서 검색」** 버튼으로 공식 페이지를 열어 직접 이용 조건을 확인하고 내려받은 TXT 파일을 가져오도록 연계합니다.
   - **판본 대조**: 검색 결과에서 첫 번째 판본을 가져온 뒤 다른 후보의 **「판본 대조」** 버튼을 누르면 두 독립 판본의 행별 일치·차이·누락 의심을 대조할 수 있습니다. 비교 자료가 하나뿐이면 `다른 판본과 대조하지 못함`을 표시합니다.

2. **성경 본문 (전용 어댑터)**
   - **개역한글판 (1961)**: 대한성서공회 안내 기준 저작재산권 보호기간이 2011년 12월 31일 종료되었습니다. 구약/신약 → 책(66권) → 장 → 시작 절 ~ 종료 절을 지정해 가져오며, 절 번호 유지·요청 범위 밖 절 제외·절 누락 감지·번역본 혼합 금지를 자동 검증합니다.
   - **King James Version (영문, 1769)**: 퍼블릭 도메인 영문 성경 지원(영국 Crown Copyright 특례 안내 병기).
   - **개역개정판(1998) 및 현대 번역본**: 저작권 보호 대상이므로 개역한글판과 동일 취급하지 않고 자동 가져오기를 차단(`RESTRICTED`)합니다.

3. **URL에서 가져오기**
   - HTTPS 우선, `localhost` 및 사설 IP 차단, 리다이렉트 대상 재검사, `robots.txt` 준수, 응답 크기(5 MB)·시간(12초) 제한.
   - HTML 내 `<script>`, `<style>`, 메뉴·사이드바·푸터를 제거해 순수 텍스트만 추출합니다.
   - 일반 웹사이트는 자동으로 이용 가능 판정하지 않으며 `UNKNOWN` 또는 `REVIEW_REQUIRED`로 표시합니다.

4. **파일 첨부 · 드래그앤드랍 · 직접 입력**
   - 본문 칸의 **파일 첨부** 버튼이나 드래그앤드랍으로 긴 본문 파일만 첨부해도 다음 단계로 진행할 수 있습니다.
   - **TXT / MD / SRT / HTML / HTM**: UTF-8, UTF-8 BOM, UTF-16, EUC-KR(CP949) 자동 감지. SRT는 대사만, HTML은 메뉴·스크립트를 빼고 본문을 추출합니다.
   - **DOCX**: 순수 본문 문단 추출 지원(머리글·각주·표 누락 가능성 안내 표시).
   - **PDF**: 다단·OCR 오류 위험 때문에 자동 추출을 지원하지 않습니다.
   - 직접 붙여넣거나 가져온 본문을 화면에서 바로 고칠 수 있습니다.

5. **제미나이로 원문 가져오기**
   - 장르·저자·제목만으로 Gemini(기존 Chrome 확장 + Native Host 텍스트 작업 경로)에 원문을 요청하고, 응답을 본문 칸에 채웁니다.
   - 확장이 연결되지 않았으면 연결 안내를 보여 주고 보내지 않습니다. 가져온 뒤 반드시 사용자가 검토·수정할 수 있습니다.
   - Gemini가 전문을 주지 않거나 거절하면 이유를 알리고, 파일 첨부나 직접 입력으로 이어가면 됩니다.

## 3. 저작권 검토 상태 (6종, 저장 호환용)

기존 프로젝트 파일과의 호환을 위해 내부 메타데이터는 유지하지만, **저작권 미확인만으로 다음 단계나 편집실 전달을 막지 않습니다.**

| 상태 | 의미 |
| --- | --- |
| `PUBLIC_DOMAIN_VERIFIED` | 저작재산권 보호기간 만료가 신뢰 가능한 근거로 확인됨 |
| `LICENSE_VERIFIED` | 명시적 이용허락(CC 등)이 확인됨 (상업적 이용·2차적저작물·출처 표기 조건 함께 표시) |
| `USER_RIGHTS_DECLARED` | 사용자가 권리 보유 또는 이용허락 확보를 직접 신고함 (시스템 검증과 구분) |
| `REVIEW_REQUIRED` | 공동저작물·무명/이명·번역저작물·국외저작물·경과규정 등 추가 확인 필요 |
| `RESTRICTED` | 저작권 보호 중이거나 확인된 허락 범위를 벗어남 |
| `UNKNOWN` | 판단할 저작권 정보 부족 (자동 승인 차단) |

- 작가 사망연도가 없으면 임의로 추정하지 않습니다.
- 번역저작물(예: 영문 원작의 한국어 번역본)은 원작과 별도의 번역자 권리를 구분해 `REVIEW_REQUIRED`로 안내합니다.
- 모든 원문은 **원문 로컬 저장, AI 분석(외부 Gemini 전송), 낭독, 자막, 영상 제작, 외부 공개(YouTube 등), 수익화** 7가지 용도별 허용 범위를 함께 표시합니다.

## 4. 원문 확정, 버전 이력 및 변경 영향 관리

- **「이 원문을 기준 원문으로 확정」** 시 확정 원문, 제목, 저자·번역자, 판본, 출처 URL, 가져온 날짜, 저작권 검토 상태·근거, 승인 날짜, **SHA-256 해시**, **버전 번호(`v1`, `v2`…)**가 `project.json`에 저장됩니다.
- 시 원문의 줄바꿈·연 구분·고어·띄어쓰기는 자동으로 수정하지 않습니다.
- 기획 분석 이후 기준 원문을 수정하면 영향 경고창을 표시하며, 승인 시:
  1. 기존 원문을 `originalHistory` 이력으로 보존합니다.
  2. 새 원문 버전을 생성합니다.
  3. 기획 분석·스토리보드·생성 프롬프트·편집안·자막에 **재검토 필요** 배너를 표시합니다.
  4. **이미 확보한 미디어 파일(`assets`)은 임의로 삭제하지 않습니다.**
- AI 기획 분석을 시작하면 확정된 기준 원문이 원형 그대로 외부 Gemini 서비스로 전송되며, 화면에 이를 명확히 안내합니다.
